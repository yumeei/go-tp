Pour clone le projet: ```git clone https://github.com/yumeei/go-tp.git```

Pour lancer le projet: ```go run .\main.go```

### Objectifs:
- Day 1: Créer un mini CRM en ligne de commande

  Fonctionnalités:
  - Afficher un menu principal en boucle
  - Ajouter un contact (ID, Nom, Prénom, Email)
  - Lister tous les contacts
  - Mettre à jour un contact
  - Supprimer un contact
  - Quitter l'application
  - (Ajouter un contact grâce à des flags)
